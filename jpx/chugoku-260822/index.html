神戸 -> 宍粟 -> 新戸倉トンネル -> 鳥取西IC -> 米子（１日目）約274Km

行程

(クリックして拡大)
  • 神戸から下道で宍粟へ行き、右折しN29に流入
    • 西神地区経由でN175に入り北行
    • G指示で、N175の市場東交差点で左折K18 -> K349沿に加西市南西部を北西方向に進む
      • 反省：市場東では曲がらず、N175をこのまま加東市まで北上、N372との立体交差で側道に降り、左折しN372を西行、フラワーセンターの標識方向に右折、K24/K371/サイサイロードに流入し北条市へ、実質直進で福崎町、宍粟市方向のK23に流入の方が走りやすい
    • 加西市西谷交差点左折しK23に入る
    • K23を福崎町、宍粟市方向にN29まで進む
  • N29を北上し、E29に流入
    • 山道を上り、新戸倉トンネル通過し、山道を下る快走路
    • E29鳥取道(無料区間)の標識でK324河原方面に左折し、16Km進む
    • E29鳥取道(無料区間)の高架下をくぐり、右折しE29に流入
  • E29を西行、鳥取西ICからE9(無料区間)に流入、米子方面へ
    • 途中、大栄東伯ICでN9に降り、逢束で給油、田舎道経由で琴浦東ICでE9に復帰
  • 米子南ICで降り、G指示で左折し観音寺経由でN9に向かい、左折
    • 反省: 米子市内の標識通り走った方が
  • N9沿いに米子市内へ
  • ビジネス旅館/ホテルさつま(素泊)
  • 夕食: 炭火割烹、籠の鳥　大山

米子 -> 美保神社・美保関灯台 -> 江島大橋 -> 松山城 -> 出雲大社 -> 益田市（２日目）約274Km

行程

(クリックして拡大)
  • 宿から境水道大橋経由で美保神社へ（無料駐車場は少し手前）
  • さらに進み美保関灯台へ（無料駐車場）
  • 江島大橋・K260経由で松山城へ
  • N431経由で宍道湖の北側を通り、出雲大社へ(無料の参拝者第2駐車場、砂地注意)
  • N431経由で稲佐の浜(無料駐車場)
  • N431経由からくにびき海岸道路・キラキラビーチへ
  • E9方面に進み、出雲多伎ICからE9に流入
  • E9/N9を西行、浜田市を通過、益田市に(実際は少々内陸までN9で進み、益田市に戻った)
  • 瑞穂イン石見益田（簡易宿泊所、素泊）
  • お食事処 味(とんかつ定食)

益田市 -> 須佐ホルンフェス -> 萩反射炉 -> 青島大橋 -> 千畳敷 -> 元乃隅神社 -> 角島大橋 -> 角島灯台 -> 下関市小月 -> 山口市（３日目）約286Km

行程

(クリックして拡大)
  • N191を西行
  • 須佐ホルンフェスの標識でK305へ右折
  • 須佐ホルンフェス（駐車場無料）
  • N191に戻り、西行再開し、萩反射炉へ（駐車場無料）
  • N191を西行再開し、長門湯元温泉の標識で、美祢、青海島方向に左折しK34に流入
  • 直ぐ、K282に右折し、仙崎漁港沿いにK56経由で青海大橋へ、
  • 青海島へ入り、そのままK283で島の端の日露兵士の墓まで行き、またK283を戻る
  • 青海大橋を渡りK56/K282をもどり、道の駅 センザキッチンで休憩
  • K282を南に少し進み、下関の標識で右折、ショートカットでN191に進む
  • 千畳敷の小さな標識で右折、標識にしたがい千畳敷へ（無料駐車場）
  • 標識にしたがい、元乃隅神社へ（有料駐車場）
  • 標識にしたがい戻り、千畳敷には行かず広域農道のような道で人丸駅近くに出て、N191に戻る（実際には少々迷った）
  • N191（風波のクロスロード）を西行、ローソン豊北阿川店前で右折し（実際はローソンで休息）
  • 国道ではない風波のクロスロードを北行し角島大橋へ
  • 角島大橋から、角島に渡り、K276で角島灯台へ（有料駐車場）
  • 角島大橋から戻り、右折しK275経由でN191に流入、南行
  • K35(豊浦菊川線、途中少々細かった、菊川でN491に出る)
  • N491で右折南行、下関市小月でN2に出て左折
  • N2を東行、N190に入り、安いガソリンスタンドへ（日本海側・内陸は、スタンドが少なくカード使えないとか高価と問題も多い）
  • N190から左折しN2に抜ける
  • N2を東行、藤川ICでK6へ（E2/N2からN9へのバイパス？）朝田ICでN9へ
  • N9を北行、山口へ陶湯田線で右折しホテルへ
  • ビジネスホテルうえの（山口市、湯田温泉）(素泊)
  • 夕食：コンビニ飯

山口市 -> 瑠璃光寺 -> 秋吉台 -> 秋吉カルストロード -> 宇部市・琴崎八幡宮 -> 周南市大島 -> 笠戸大橋 -> 新笠戸ドック -> 岩国市・錦帯橋 （４日目）約266Km

行程

(クリックして拡大)
  • ホテルからN9に出て右折、N9を北行で瑠璃光寺に（無料駐車場）
  • N9を戻り、秋芳洞の標識で右折しN435に入る
  • N435が左折で長門・美祢との標識の交差点を直進しK242に流入し秋吉台に進む
  • K242(カルストロード)を北に進み、標識にしたがい秋吉台カルスト展望台に上がる（無料駐車場）
  • K242(カルストロード)に戻り、景色の良いところを往復
  • 秋吉台カルスト展望台入り口を通り過ぎ、N435を進む
  • 左折してK31へ、美祢東IC下を通り過ぎ、N490に右折進行
  • N490を南行し、N2に突き当たったら、右折しN490とN2の共通区間を南に進む
  • N490で、左折しN490を南行、宇部市の琴崎八幡宮へ
  • 琴崎八幡宮から、N490をさらに南行、宇部市街地へ
  • N190の交差点で左折しN190沿いに東に進む、
  • 宇部南ICからK6山口宇部道路を北行
  • N2に流出、N2を東行、山口南ICからE2に流入
  • E2を東行、徳山東ICで出て、海の方へ進み、K170で周南市の大島へ(写真中の「周防大島」は間違い)
  • 大島からK170を戻り、K366で右折、ボートレース徳山前を通りK366を東行
  • K366から右折し笠戸大橋を渡る
  • 笠戸島内をK173で進む（大型車両多し）
  • 新笠戸ドックまで進み戻り、K366に出ると左折して少しさらに戻る
  • 北に抜けられる道K63へ右折、K140を右折、N2東行、
  • K15を東行（岩国に行くN2の近道）
  • 岩国市街地を通過、
  • N2に合流、N2を東北行
  • HOTEL AZ 山口岩国店（素泊）
  • 市内の錦帯橋へ往復(無料駐車場が拳骨大の石たらけの河原にある)
  • 夕食: FASTFOOD

岩国市 -> 宮島口・宮島・弥山 -> 神戸（５日目）約342Km

行程

(クリックして拡大)
  • ホテルからN2を北に進み、ＪＲ宮島口 自転車駐車場へ。(無料、自動二輪可)
  • JRの連絡船で宮島へ
  • 厳島神社参拝
  • 宮島ロープウエーで獅子岩駅へ
  • 弥山 展望台まで、ハイキング往復
  • ロープウエーで下山、JR連絡船で宮島口へ
  • ＪＲ宮島口 自転車駐車場から、N2で東行
  • 東雲ICから広島高速で北行、広島東ICでE2東行に流入
  • ずっと、E2を走行、小野三木ICでN175南行に流出
  • 西神・山麓バイパス・長田経由で神戸市街地へ
